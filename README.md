# Planora

Plan your day. Remember your goals.

## Status project

Saat ini repository berisi **template awal dashboard** untuk Planora.

- Fokus tahap ini: rancangan UI dashboard dan interaksi demo.
- Belum ada database online.
- Belum ada integrasi Google Sheets.
- Data demo pada halaman saat ini disimpan di browser perangkat (local storage), bukan disinkronkan antar perangkat.

## Menjalankan

Buka `index.html` melalui GitHub Pages atau browser untuk melihat template.

## Rencana tahap berikutnya

1. Sempurnakan alur dan tampilan halaman.
2. Tentukan struktur data.
3. Baru pilih dan sambungkan database.
